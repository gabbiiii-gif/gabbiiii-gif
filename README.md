- **[FrostERP](https://frosterp.com.br)** — Sistema de gestão para empresas de refrigeração e climatização: ordens de serviço, financeiro, estoque e agenda. App web + mobile.
- **[DespachaGov](https://despachagov.com)** — Plataforma B2G de gestão de demandas de manutenção para secretarias municipais, com SLA e trilha de auditoria.
- **[MinasCaixa](https://github.com/gabbiiii-gif/Minas)** — Livro-caixa digital desktop (Electron) para a Minas Auto Peças.
- **[Site Letícia Pais](https://www.leticiapaispsi.com.br)** — Site institucional para psicóloga, com blog e agendamento.
- **[Scouts Games Cup](https://scouts-games-cup-2-0.vercel.app)** — Site de inscrição para campeonato de e-sports.
